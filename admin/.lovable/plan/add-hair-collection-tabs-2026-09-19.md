# Add Hair Collection Tabs

## Goal
Add a BIGCROWN HAIR section inspired by the reference store’s “Hair Bundles”, “Crochet Hair”, and “Trending Colors” tabs.

## What will be built
- Add a three-tab collection section below Best Sellers.
- Make “Hair Bundles” active by default and switch the visible products instantly when another tab is selected.
- Show a polished product row for each collection with product imagery, sale badges, favorites, prices, ratings, sold counts, and add-to-bag controls.
- Connect the section’s buttons to the existing cart and favorites interactions.
- Keep the layout horizontally scrollable on small screens and a clean multi-column grid on larger screens.
- Use BIGCROWN’s purple palette, typography, and existing visual language rather than copying ISEE branding.

## Content direction
- Hair Bundles: curly, straight, body-wave, and natural-texture bundles.
- Crochet Hair: feather crochet, boho curl, and lightweight braid styles.
- Trending Colors: burgundy, honey blonde, highlighted brown, and natural-black mixes.
- Use locally generated/store-owned imagery only; no hotlinked reference-site assets.

## Technical details
- Extend the homepage’s product data with three categorized collections.
- Add accessible tab buttons with selected states and keyboard-friendly controls.
- Reuse the existing product-card interaction patterns so cart and favorite counts remain consistent.
- Verify the section visually on desktop and mobile and confirm there are no browser errors.
